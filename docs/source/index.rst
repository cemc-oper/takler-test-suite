Takler Test Suite 文档
======================

Takler Test Suite 通过公开 API 和客户端验证 `Takler <https://github.com/cemc-oper/takler>`_ 的工作流行为。
套件提供离线定义检查、使用本地服务和真实作业的在线测试，以及 CLI/TUI 操作演练。

* :doc:`quickstart` 介绍如何运行第一个用例并查看结果。
* :doc:`coverage` 按功能列出用例及其运行方式。
* :doc:`contributing` 介绍如何添加用例、运行设施测试和构建文档。
