# 用例目录

[`catalog.toml`](../../catalog.toml) 登记用例和实现入口。运行 `python3 -B run.py list` 可查看检出版本中的用例状态。定义和参数用例使用 `--profile offline`，其余使用 `--profile local`。运行命令见[运行指南](quickstart.md)。

## 定义与参数（offline）

| 用例 | 验证内容 |
| --- | --- |
| DEF-001 | 通过公开 API 创建流程树，检查节点路径、类型和层级 |
| DEF-002 | 检查无效定义和结构约束的诊断 |
| DEF-003 | 导出定义并重新构建，检查序列化往返结果 |
| PAR-001 | 检查参数的继承和覆盖 |
| PAR-002 | 检查模板、`include` 和作业脚本准备 |

## 服务、部署与执行（local）

| 用例 | 验证内容 |
| --- | --- |
| BAS-001 | 服务配置、启动、连接和停止 |
| BAS-002 | gRPC/HTTP 传输选择与连接失败 |
| BAS-003 | 客户端参数、环境变量和连接文件的优先级 |
| DPL-001 | 加载流程后查询部署结果 |
| DPL-002 | 无效定义和重复部署的拒绝 |
| DPL-003 | 流程更新和替换保护 |
| EXE-001 | 本地 Shell 作业执行、child 回报及产物 |
| EXE-002 | 作业提交失败和提交结果不确定时的行为 |
| EXE-003 | takflow 导出、Takler 调度和 orvix local 提交的成功与失败路径 |

EXE-002 和 EXE-003 需要真实 orvix。EXE-003 还需要 takflow，可配合 [CLI/TUI 操作演练](operator-exercise.md) 观察结果。[环境准备](baseline.md)

## 调度与控制（local）

| 用例 | 验证内容 |
| --- | --- |
| DEP-001 | 前置依赖、并行分支与下游汇合 |
| DEP-002 | 事件满足后放行作业 |
| DEP-003 | meter 阈值和组合条件 |
| RES-001 | 单一资源限制下的并发和令牌释放 |
| RES-002 | 跨流程争用资源与旧作业退出后重排 |
| CTL-001 | 节点暂停与服务 halted 的作用范围 |
| CTL-002 | 重排与旧 attempt 的隔离 |
| CTL-003 | `force` 与混合批量控制的逐项结果 |
| TIM-001 | 本地真实时钟到达目标分钟后放行，结合暂停与依赖 |
| TIM-002 | `RepeatDate` 的三轮实际执行及各轮 attempt |

依赖和资源用例通过文件屏障控制实际作业，同时核对公开任务状态。TIM-001 依赖真实时间，请给目标分钟留出运行时间。

## 查询与展示（local）

| 用例 | 验证内容 |
| --- | --- |
| QRY-001 | 范围摘要、深度选择和实时详情 |
| QRY-002 | 增量同步、摘要续页过期、重连和视图重建 |
| QRY-003 | 固定版本的完整读取、宽字段和取消后的行为 |
| QRY-004 | CLI 的四类任务状态和详情展示 |
| QRY-005 | 定位和读取同一文件系统中的作业输出 |

QRY-002 会等待 120 秒的摘要页保留期过去。QRY-004 的 TUI 检查使用[独立演练入口](operator-exercise.md#独立-tui-演练)。

## 安全与恢复（local）

| 用例 | 验证内容 |
| --- | --- |
| SEC-001 | 操作凭据与授权范围 |
| SEC-002 | TLS 信任链、证书名称和客户端校验 |
| SEC-003 | 拒绝非法访问及公开响应中的敏感字段检查 |
| SEC-004 | child 身份及实例凭据 |
| RCV-001 | 正常停机与同地址恢复后接收原作业回报 |
| RCV-002 | 损坏的主备 checkpoint 与服务启动拒绝 |
| RCV-003 | `SIGKILL` 后的 checkpoint 丢失窗口及外部进程 |

恢复用例使用真实 checkpoint 周期。SEC-002、RCV-003 和 RCV-004 的额外系统要求见[环境准备](baseline.md)。
